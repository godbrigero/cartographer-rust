Overview

cartographer-rust is a pure-Rust port of Google Cartographer (real-time 2D/3D LiDAR SLAM): local SLAM (scan matching into submaps), the global pose graph (constraint search with branch-and-bound scan matching, sparse pose adjustment with a Rust Ceres replacement), serialization (pbstream), the Lua configuration files and the cloud API. This report collects what the port achieves on simulated data, how much of the C++ code and its tests are ported, and how fast the hot paths are.
